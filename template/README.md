# Template

```
npm install    # also downloads the MediaPipe hand model
npm run dev    # http://localhost:5173, add #scene-id to open one scene
```

1. Copy `VIDEO_BRIEF.template.md` to `VIDEO_BRIEF.md` and write the script, one sentence per scene.
2. Replace `scenes.json`, `assets/example/` and `speaker` with your own.
3. Set the style tokens at the top of `src/style.css`.

Keys: → next · N next (hand opens it) · ← back · T replay · P teleprompter · H notes · G hand overlay · W white/ink text
